# Self-hosted fonts

Public Sans variable Latin (Fontsource 5.3.0) and IBM Plex Mono regular Latin
(Fontsource 5.3.0) are served locally. The adjacent license files are included
with their respective font distributions. No third-party font requests are made.

Sources: https://www.npmjs.com/package/@fontsource-variable/public-sans and
https://www.npmjs.com/package/@fontsource/ibm-plex-mono.
